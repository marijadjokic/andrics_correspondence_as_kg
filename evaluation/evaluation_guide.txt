EVALUATION GUIDE
================

Before running, activate the venv:
  .\.venv\Scripts\Activate.ps1


1) NER evaluation (entity recognition: PER, LOC, ORG, MISC)
-----------------------------------------------------------------
python .\evaluation\eval_ner.py --gold .\evaluation\gold_dataset_ner.csv --pred .\data\output\ner_entities.csv --out .\evaluation\ner_evaluation.csv --errors .\evaluation\ner_errors.csv

  --gold   gold (manually annotated) dataset, evaluation\gold_dataset_ner.csv
  --pred   system output being evaluated, data\output\ner_entities.csv
  --out    (optional) saves the results table (Precision/Recall/F1 per type) as CSV
  --error  (optional) saves the error analysis (false negatives / false positives per text) as CSV


2) NEL evaluation (entity linking to Wikidata)
-----------------------------------------------------------------
python .\evaluation\eval_nel.py --gold .\evaluation\gold_dataset_nel.csv --pred .\data\output\ner_nel_entities.csv --out .\evaluation\nel_evaluation.csv --errors .\evaluation\nel_errors.csv

  --gold   gold dataset with a wikidata_uri column, evaluation\gold_dataset_nel.csv
  --pred   system output being evaluated, data\output\ner_nel_entities.csv
  --out    (optional) saves the results table (Precision/Recall/F1/Accuracy per type) as CSV
  --error  (optional) saves the error analysis (false negatives / false positives per text) as CSV

Note: NER evaluation compares entity text + type (regardless of span/position in the
letter), while NEL evaluation checks whether an entity is linked to the correct
wikidata_uri. Run eval_ner.py first to check recognition quality, then eval_nel.py to
check linking quality.
